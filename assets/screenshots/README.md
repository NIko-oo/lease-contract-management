## 约定

- 宽度 1600–1920px，PNG 格式，只截内容区
- 截图前切到浅色主题、浏览器缩放 100%
- 涉及真实业务数据的字段用**实心色块**整格覆盖，不要用模糊或马赛克
- 侧边栏底部用户名与头像必须遮住
- 每张图在 README 下配一行 `> 说明`，若截图含仓库未开源的客制化菜单，需注明这些功能不包含在本仓库中
