## 功能列表

### 合同管理页面（`/contracts`）
- **页面目标**: 合同信息的录入、查看、编辑和提交审核
- **功能点**:
  - **合同列表**: 展示合同编号、承租方、出租方、合同起止日期、合同签署日期、创建日期、修改日期、支付方式、审核状态、合同状态，支持分页和基础筛选。创建日期取 `_created_at`、修改日期取 `_updated_at`（平台系统字段，任一业务动作改写该合同行时刷新——含编辑、提交、审核、变更审核通过、终止审核通过，故它不是审核通过时间）；两列由列表接口以 ISO 串透出 `_createdAt` / `_updatedAt`，前端按本地时区取日期、只显示 `YYYY-MM-DD`（不显示时分）；签署日期取 `contracts.sign_date`，原样按 `YYYY-MM-DD` 显示，空值显示 `-`
  - **筛选查询**: 单行排列（窄屏自动换行）——关键词（合同编号 / 承租方 / 出租方模糊，固定宽度不随容器撑满）+ 状态下拉 + 日期筛选，日期筛选由「日期类型」（合同签署日期 / 创建日期 / 修改日期，默认签署日期）配两个 `type=date` 输入组成「起始 至 截止」区间，只填一侧即单边限制。全部筛选在前端本地过滤（列表接口不带分页参数一次拉全量，翻页也是前端切片）；比较时创建/修改日期同样先按本地时区折成 `YYYY-MM-DD` 再比，与单元格显示口径一致，避免 UTC 串跨天导致「看到的日期筛不出来」；所选字段为空的合同在设定区间后被排除
  - **新建合同**: 跳转至合同录入页，填写基础信息（合同编号、出租方、承租方、起止日期、是否收水电费、支付方式）和租期分段（支持动态添加N个阶段，每个阶段含起止日期、月租金、月物业费）
  - **合同详情**: 查看合同完整信息，包括所有租期阶段明细
  - **编辑合同**: 仅"待审核"或"被驳回"状态可编辑
  - **提交审核**: 将合同提交至财务审核流程
  - **合同变更**: 已审核通过的合同可变更，录入补充协议编号、变更日期、变更方式（减免/增加租金或物业费）、分段配置，变更提交后进入待审核状态，财务审核通过后自动更新台账
  - **变更记录查看**: 合同列表可展开查看该合同的所有变更记录（含审核状态、审核意见）
  - **状态标识**: 待审核/审核通过/审核驳回/已终止

### 客户管理页面（`/customers`）
- **页面目标**: 管理客户基本信息，支持新建、编辑、冻结/解冻、导出
- **功能点**:
  - **客户列表**: 展示客户编码、公司名称、统一社会信用代码、银行账户、状态，支持搜索和状态筛选
  - **新建客户**: 录入客户编码、公司名称、统一社会信用代码、银行账户，客户编码唯一
  - **编辑客户**: 修改客户信息（客户编码可修改，需唯一）
  - **冻结/解冻**: 冻结客户后不可被合同录入时搜索选中
  - **导出 Excel**: 将当前筛选条件下的客户数据导出为 xlsx 文件

### 合同录入页面（`/contracts/create`）
- **页面目标**: 表单形式录入新合同完整信息
- **功能点**:
  - **基础信息表单**: 合同编号、出租方、承租方、合同总起止日期、是否收取水电费（开关）、租金支付方式（下拉选择）
  - **租期分段配置**: 动态添加/删除租期阶段，每个阶段包含：阶段起止日期、月租金、月物业费
  - **表单验证**: 必填项校验、日期逻辑校验（阶段日期不重叠、在总起止范围内）
  - **保存草稿**: 暂存未完成的合同信息
  - **提交审核**: 完成后直接提交财务审核

### 合同详情页面（`/contracts/:id`）
- **页面目标**: 展示单个合同的完整信息和操作历史
- **功能点**:
  - **基础信息展示**: 合同编号、出租方、承租方、总起止日期、支付方式等
  - **租期阶段明细**: 表格展示所有阶段起止日期、月租金、月物业费
  - **审核记录**: 显示财务审核历史（通过/驳回及原因）
  - **终止记录**: 如已终止，显示终止日期和审批信息
  - **台账入口**: 跳转查看该合同的台账明细

### 合同终止页面（`/terminations`）
- **页面目标**: 行政人员提交终止申请，查看申请状态
- **功能点**:
  - **终止申请列表**: 展示申请编号、合同编号、承租方、申请终止日期、审核状态；列表上方支持按合同编号、承租方前端模糊筛选
  - **提交终止申请**: 选择已通过审核的合同，填写申请终止日期，提交财务审核
  - **状态跟踪**: 待审核/已通过/已驳回及驳回原因
  - **撤回申请**: 待审核状态可撤回申请

### 财务审核页面（`/finance/review`）
- **页面目标**: 财务人员复核新录入合同和终止申请
- **功能点**:
  - **待审核合同列表**: 展示待审核的新合同（基本信息+租期阶段概览）
  - **待审核终止申请**: 展示待审核的终止申请
  - **待审核变更**: 展示待审核的合同变更申请（补充协议编号、变更方式、变更起止日期、分段明细）
  - **合同复核详情**: 查看合同完整信息和租期阶段明细
  - **变更复核详情**: 查看变更完整信息和分段明细
  - **通过操作**: 审核通过，合同生效/终止生效/变更生效，自动触发生成台账（新合同通过时）或更新台账（变更通过时）。终止审核通过的台账处理包在一个 `db.transaction` 内：合同置 terminated、`period` 晚于终止月的台账行置 terminated、**终止月内 `stage_start_date` 晚于终止日的台账行同样置 terminated**（口径与 `checkPeriod` 的「终止日后不计费」一致，覆盖同月多阶段行场景），终止日所在行按天数比例改写 `amendment_rent`/`amendment_property_fee`；停用水电费租户、飞书通知放在事务提交后，失败不回滚终止结果
  - **驳回操作**: 填写驳回原因，退回修改
  - **审核历史**: 查看已审核记录（合同审核历史、变更审核历史、终止审核历史）

### 台账管理页面（`/ledger`）
- **页面目标**: 查看自动生成的台账明细，登记实际收款
- **功能点**:
  - **台账列表**: 按自然月拆分的明细记录，字段包括合同编号、承租方、租赁面积、所属期（年月）、阶段实际起止日期、合同租金、合同物业费、变更合同编号、变更合同租金、变更合同物业费、应收租金、应收物业费、支付方式、最后缴纳期限、收款状态。租赁面积是合同级单值，由列表接口按 contract_id 从 contracts.lease_area 批量带出（不改 ledger_items 表结构），合同未填写时显示 `-`；应收租金=变更合同租金??合同租金，应收物业费同理；表头可拖动调节列宽，进入页面后按当前数据自动适配列宽（避免列宽过窄导致内容重叠）
  - **筛选查询**: 按合同编号、承租方、房产名称（模糊匹配）、所属期、逾期状态、收款状态筛选，输入即自动查询；筛选卡片右上角提供「重置筛选」按钮一键清空全部条件
  - **收款录入**: 收款弹窗信息区展示合同编号/承租方/租户编码/默认所属期（租户编码由列表接口按租户名称精确匹配 customers.companyName 动态带出，匹配不到显示 -）；收款弹窗支持动态多行（租金/物业费，可新增行），每行含类型、金额、收款日期、所属期（下拉=该合同未收齐台账期，默认当前行 period）；弹窗初始化仅展示仍有待收余额的项目行（只有待收租金时仅显示租金行，已收齐时无录入行）；每行展示该期该类型应收/已收/剩余应收金额（口径为**合同+所属期**：应收取该期全部未终止台账行之和、已收取 `receive_records` 该期聚合，同月多行时不按行取数，否则弹窗的分母与后端校验的分子不同维度），并提供"一键收齐"按钮（自动扣除同期间类型其他行已填金额后把剩余应收填入该行，结果按分取整，避免浮点减法漏出 `14.539999999999964` 这类尾差）；行内实时校验（金额超该期该类型剩余应收红字拒绝、小于应收黄字警示），保存时若该合同+所属期最终状态仍为部分收款则二次确认；保存后先写入收款报表（receive_records）再由系统按合同+所属期汇总回写 ledger_items——期级已收按 `stage_start_date` 升序逐行分摊（先填满前一行自身应收，剩余落到下一行），每行各自判定 unpaid/partial/paid，已终止行不参与分摊，支持一次分多笔覆盖多期；发票编号不在收款时填写（收款时发票未开具），仅可在收款报表页补录
  - **收款记录查看与删除**: 收款状态为已收齐的台账行点击"收款"仅展示已收款记录（收款类型、金额、收款日期、单位数量，与录入表格同列格式，弹窗标题为"收款记录"，仅"关闭"按钮）；已收款记录按 `contractId`+`period` 取数（`GET /api/receipts`），同月多行时各行看到的是同一期的全部流水，与期级回写口径一致；未收齐行存在历史收款记录时也展示该区块；每条记录提供删除按钮（Trash2Icon），删除复用收款报表 DELETE /api/receipts/:id 能力并自动回写台账收齐状态，删除后刷新该期收款记录与台账列表，全部在台账管理页内完成
  - **水电费收款录入**: 跳转至水电费登记表登记水电费（针对标记需收水电费的合同）
  - **收款状态更新**: 未收/部分收款/已收齐/无需收款自动计算；应收租金与应收物业费均为 0 的期间（免租期）自动置为「无需收款」（no_payment_required），该行不显示收款按钮，不参与逾期提醒与对账单取数，台账页「逾期天数」列（含导出）固定显示「未逾期」；已终止（terminated）优先级高于无需收款，终止行不被覆盖
  - **导出台账**: 导出Excel格式（xlsx）的台账明细，含列宽自动设置，文件名 `台账明细_日期.xlsx`

### 收款报表页面（`/receipts`）
- **页面目标**: 按收款明细查看全部收款记录（台账/水电费收款统一入账），支持筛选、行内补录发票编号
- **页面权限**: 独立权限点 `read:Receipt`（查看）/ `edit:Receipt`（发票编号编辑），默认绑定 super_admin、finance 角色（authz_permissions + authz_role_permissions，SQL 见 data/authz_receipt_permissions.sql）
- **功能点**:
  - **收款列表**: 字段包括房产名称、合同编号（水/电费收款显示 -）、租户编码、租户名称、收款类型（租金/物业费/水费/电费 Badge）、收款日期、款项所属期、单位（平方米/月/吨/度）、单位数量、收款金额、发票编号；表头可拖动调节列宽，进入页面后自动适配列宽
  - **筛选查询**: 按房产名称（模糊）、合同编号（模糊）、租户编码/租户名称（模糊关键词）、收款类型、收款日期起止、款项所属期筛选，输入即自动查询，支持分页
  - **发票编号编辑**: 单元格行内点击编辑，失焦/回车保存（PATCH /api/receipts/:id/invoice）
  - **收款明细导出**: 按当前筛选条件导出全量明细（xlsx，pageSize=9999 拉全量），文件名 `收款报表_日期.xlsx`

### 水电费管理页面（`/utilities`）
- **页面目标**: 后勤人员登记水电费，财务人员查看和录入收款
- **功能点**:
  - **需收水电费租户列表**: 由 `utility_tenants` 表驱动（`is_active=true`），按「租户+房产」维度一行一房产（同租户跨房产各房产独立一行）；新建/编辑/变更合同时勾选"收取水电费"自动写入该表（`ON CONFLICT (tenant, property_name) DO UPDATE SET is_active=true`，幂等去重），房产名由合同 property_id 实时查询 `properties` 表所得；房产名兜底：存量行 property_name 为 NULL（多房产维度改造前按租户维度写入）时，`getTenants` 从开启水电费（`has_utilities=true`）的合同中反查补齐（approved 优先、startDate 最新、排除该租户已有行的房产）
  - **租户自动停用/重新激活**: 合同终止审核通过后，若该租户+该房产名下无其他生效合同（approved 且 end_date>=今天），`utility_tenants` 中对应 (tenant, property_name) 行 `is_active` 置 false（不再出现在水电费管理页），同租户其他房产行不受影响；新合同审核通过开启水电费时自动重新激活
  - **水电费录入**: 按「租户+房产」分组、各房产独立生成期间（最早开始月→最晚结束月），登记/收款/明细弹窗均展示房产名称；录入字段包括实际用电量、电费单价、实际用水量、水费单价（后勤人员权限）；所属期为下拉选择，仅列出该租户该房产合同期间内、未登记、且早于当前月的月份；从"待登记所属期"入口进入时锁定预设期间
  - **水电费计算**: 自动计算电费总额（用电量×单价）、水费总额（用水量×单价）
  - **水电费登记记录表**: 展示历史录入记录，列顺序为 房产名称（第一列，经合同映射，映射数据源为全量合同（含已终止，pageSize:500 不带 status 拉取），保证已终止合同的历史登记记录仍显示房产名称）→承租方→合同编号→所属期→电费总额→水费总额→费用合计→已收金额→收款状态→最后缴纳期限→逾期天数→登记日期→收款日期；支持按 房产名称（选项取有登记记录的房产去重）、承租方（模糊搜索）、费用所属期、收款所属期（收款日期 receiveDate 所在月份 YYYY-MM 去重）、收款状态 筛选（筛选区左对齐，每项上方带小字标签，顺序固定），筛选联动即时生效
  - **登记记录导出**: 卡片标题栏「导出 Excel」按钮，按当前筛选条件导出全量明细（17 列，含房产名称），文件名 `水电费登记记录_日期.xlsx`
  - **登记记录表格展示体验**: 与台账管理页一致——进入页面/数据加载完成后自动适配列宽一次（canvas 测量文字宽度，最小 60px；不随筛选变化反复重测，避免测量抖动导致列宽偏窄重叠）；承租方列按全部登记记录全量测量最长名称校准列宽（表格分页只渲染当前页，DOM 测量不到其他页的超长公司全称，翻页后长文本会溢出遮挡，故全量测量兜底）；表头边缘可拖拽自定义列宽、双击表头该列重新自适应
  - **水电费收款登记**: 收款弹窗信息区左右两列布局（首行房产名称/所属期+未逾期收款按钮，次行租户编码/承租方，不展示合同编号；租户编码由列表接口按租户名称精确匹配 customers.companyName 动态带出，匹配不到显示 -）；打开弹窗时加载该水电费记录已录入的收款记录并展示"已收款记录"区块（类型/金额/收款日期/单位数量列），每行提供删除按钮（删除确认后经 receipt_api.remove 删除并自动回写 utility_records 已收金额，与台账页收款删除逻辑对齐）；已收齐时只读展示已收款记录（仍可删除）、隐藏录入区，底部按钮变「关闭」；收款弹窗拆为水费/电费两行（默认金额=该方向剩余应收，可改、可删行），每行展示应收/已收/剩余应收金额，并提供"一键收齐"按钮（把剩余应收填入该行）；单位数量=金额÷单价（吨/度）实时折算；行内金额超限红字拒绝、部分收款黄色警示+保存前二次确认；后端超收校验按**累计口径**（该期该类型 `receive_records` 已收 + 本次 ≤ 应收，与台账收款同构），单笔金额不超剩余应收但累计超收同样被拒；保存后先写入收款报表（receive_records）再由系统回写 utility_records（electricityReceived/waterReceived/receiveDate），支持多次分笔（含租金物业费一起收的情况在台账页登记）
  - **水电费登记记录删除**: 后勤人员可删除登记记录；该记录在 `receive_records` 中已存在关联的水/电费收款时返回 409 拒绝（`该水电费记录已存在收款，请先删除对应收款记录`）——`receive_records.ref_id` 无外键约束，先删登记会留下孤儿流水并使已收金额回写无法追溯
  - **费用明细查看**: 查看每期水电费详细数据

### 合同统计页面（`/statistics`）
- **页面目标**: 按合同维度汇总展示统计信息
- **页面布局**: 页面最顶部为「新增合同对年收入的影响」卡片，其后为标题区（`合同统计` + `按合同维度汇总展示统计信息` + `导出统计表` 下拉按钮，导出 Excel/CSV），再下方为统计汇总卡与合同汇总表
- **功能点**:
  - **新增合同对年收入的影响卡片**: 按选定合同签订年份统计新签合同/补充协议/终止合同/部分变更协议对本年利润的影响
    - **统计口径说明**: 卡片标题下方注明「本次统计只从合同口径统计合同总金额对本年的影响，未考虑物业费收入净额法对本年利润的影响（即合同统计使用总额法）」
    - **年份/状态筛选**: 合同签订年份选择器（默认当前年）+ 状态筛选（全部/新签合同/补充协议/终止合同/部分变更协议）
    - **筛选规则**: 合同签订日期(signDate)年份=所选年份；合同终止创建的合同；合同变更历史签署日期年份=所选年份（排除水电费变更）
    - **影响金额**: 租金影响利润总金额/物业费影响利润总金额/影响利润总金额（均不含税，含税转不含税除以 1+税率；终止合同为负向冲减）
    - **明细导出**: 明细表格支持导出 Excel（exportImpactExcel）
  - **合同汇总表**: 单合同一行记录，字段包括合同编号、承租方、合同总起止日期、租金总金额（各阶段月租金×月数之和）、物业费总金额
  - **金额计算**: 自动根据租期阶段计算合同总金额
  - **合同状态统计**: 正常履行/已终止/即将到期（30天内）标识
  - **汇总导出**: 导出合同汇总统计表
  - **快捷筛选**: 按合同状态、承租方筛选

### 数据看板页面（`/dashboard`）
- **页面目标**: 以房产为维度展示出租概况汇总数据，支持按年份/月份联动刷新
- **功能点**:
  - **年份/月份选择器**: 顶部筛选区，默认当前年/月，切换后数据即时刷新
  - **房产出租概况卡片**: 8 列表格（房产名称/可出租面积/已出租面积/未出租面积/加权平均出租率/期末出租率/年累计租金/年累计物业费）
  - **多卡片容器结构**: 预留后续第 2、3 卡片扩展位
- **取数逻辑**:
  - 可出租面积: `properties.rentable_area`
  - 已出租面积（期末）: 台账该月（period=YYYY-MM 且 status!=terminated）经 contract_id->contracts.property_id 归属房产 -> 期末租户集合（tenant 去重，取合同侧）-> 该房产期末在租合同（approved 且日期覆盖当月）lease_area 累加
  - 未出租面积: 可出租面积 - 已出租面积（夹取 >= 0）
  - 加权平均出租率: 年累计出租面积（1~M 逐月求和）/ M / 可出租面积
  - 期末出租率: 期末已出租面积 / 可出租面积
  - 年累计租金: 1~M 月、status!=terminated 台账，COALESCE(amendment_rent, monthly_rent) 按 property_id 归属求和
  - 年累计物业费: 同上，COALESCE(amendment_property_fee, monthly_property_fee)
- **边界处理**: 可出租面积 <= 0 时出租率/未出租面积返回 null（前端显示 `-`）；台账剔除 status='terminated'；房产归属一律用 contract_id -> contracts.property_id
- **权限**: `@Can('read', 'Dashboard')`，logistics 角色不可见

### 对账单页面（`/statements`）
- **页面目标**: 生成标准化对账单供租户确认
- **功能点**:
  - **两种生成条件**: ① 按租金费用所属期生成（对账月份及之前未收/未收齐的租金及水电费明细）② 按收款所属期生成（缴纳期限月份及之前的未收/未收齐明细）
  - **按租户汇总**: 按承租方维度分组汇总，显示该租户所有历史未收款明细，按支付方式（月付/季付）分组勾选
  - **对账单预览**: 生成标准化对账单格式（含公司抬头、租户信息、明细列表、合计金额）
  - **导出PDF**: 导出标准化对账单PDF文件（可多租户批量导出）
  - **打印功能**: 直接打印对账单
- **取数过滤规则**: 台账行 `status='terminated'` 一律排除；已终止合同在终止月份之后的期间排除（`period > terminationDate.substring(0,7)`）；合同映射使用本次请求的局部 Map（首次生成时 state 未更新导致终止过滤失效的坑已修复）

### 逾期提醒页面（`/overdue`）
- **页面目标**: 查询逾期未收款项并发送飞书提醒给跟进人员
- **功能点**:
  - **跟进人员配置**: 分别为租金物业费逾期、水电费逾期、水电费未登记三种类型配置跟进人员、定时提醒开关和提醒日（每月几号提醒，默认20号）
  - **逾期租金物业费**: 展示台账中未收/部分收款且已过最后缴纳期限的明细，含合同编号、所属期、应收/未交金额、逾期天数；应收按 `amendment_* != null ? amendment_* : 原值` 取值（变更减免为 0 时应收就是 0，不做 falsy 回落），与台账列表同一口径
  - **逾期水电费**: 展示水电费台账中未收齐且已过期的明细，含房产名称（置第一列）、承租方、所属期、应收/未交金额、逾期天数
  - **水电费未登记汇总**: 按「合同+期间」维度逐合同判断（同租户跨房产时各合同互不影响），展示房产名称（置第一列）、承租方、未登记月份、未登记期数；未登记期间从 2026-01 起算（早于该月的期间不纳入统计，与水电费管理页登记期间下限一致）
  - **一键提醒**: 点击按钮发送飞书通知给跟进人员
  - **自动化定时提醒**: 配置定时任务（默认工作日9:00），自动检查逾期并推送飞书消息
